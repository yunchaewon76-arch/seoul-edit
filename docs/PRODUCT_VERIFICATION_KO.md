# 영상 상품 및 대체품 검증 정책

- 모든 상품 카드는 영상의 **정확한 원본 장면 또는 제작자 설명란**을 확인한 후 확정한다.
- 유픽(You-Pick) 등 2차 상품 목록은 연구 후보로만 인정하며 실제 영상에서의 사용 사실을 자동 확정하지 않는다.
- **대체품(Альтернатива)**: 원제품의 사용 목적, 주요 특성, 제형과 알려진 성분 및 차이를 비교한 근거가 있어야 한다. 완벽한 대체/동등 효과를 보장하지 않는다.
- 러시아 판매 URL은 정확한 상품 상세 링크를 직접 열어 확인한다. 검색 결과/카테고리/광고 글은 구매 URL로 쓰지 않는다.
- 모스크바 기준 재고나 배송 가능성은 개별 확인 필요. 판매 페이지 발견만으로 '재고 있음' 표시 금지.
- 마지막 확인 날짜를 기록하며 오래된 URL은 검증 만료 처리한다.
- 제조사 상품 사진도 자동 자유이용이 아니다. 저작권/이용 권한 확인 없이 외부 사진을 재게시하지 않는다.
- 상품이 단순 추천인지 광고/제휴인지 구분하고 제휴 고지 필요 여부를 검토한다.
- 검증된 상품이 아직 없다면 상품 구매 버튼을 아예 보여주지 않는다.
